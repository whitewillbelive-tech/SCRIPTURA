# K-3~K-7 비공개 실자료 통합

기준 저장소는 `whitewillbelive-tech/SCRIPTURA`, 기준 커밋은 `ae08ca2bc01479f01911fe47c5c6e4391d739be9`이다. 이 작업은 별도의 `codex/scriptura-k37-private-integration` 개발 브랜치에서 수행한다. 실제 연구자료를 공개 저장소나 CI에 넣지 않고 원본을 읽기 전용으로 다룬다. 운영 DB 적재, 정본 자동 승격, `main` 병합과 운영 배포는 범위에 없다.

## 입력과 수신 상태

이번 세션에 전달된 비공개 브리지에서 D-13 기준본과 D-14~D-16 증분 두 파일의 존재를 확인했고, 제공된 사전 검사가 `READY_FOR_PRIVATE_INTEGRATION`으로 종료했다. 예전 세션에서 Library 파일을 사용할 수 없었다는 기록은 당시 환경에 관한 것이며 이번 입력 상태와 다르다.

실자료를 메모리에서 읽어 두 고정 입력의 무결성, D-13의 14계층과 증분 체크섬 45건을 확인했다. D-13은 신규 출처 47건·주장 47건이며 D-14는 신규 출처 96건·주장 98건·본문 45건이다. D-14 주장이 가리키는 본문은 기존 주소 4건을 포함해 49개다. 기존 후보 621건을 유지하고 신규 후보 288건을 연결해 총 909건이다. 초기 기준본 검사가 동일 ID·동일 레코드 반복 2,385그룹을 충돌로 처리하던 문제를 동일 기록과 상충 기록을 구분하도록 수정했다. 실제 입력에서 신규 ID 충돌과 검증된 참조의 미해결은 0건이었다.

D-16 비교 묶음은 80개이며 주장 참조 177/177과 본문 참조 81/81이 대상에 연결됐다. 80개 중 1개 묶음은 서로 다른 코퍼스·번호 체계의 두 본문을 포함하므로 하나로 병합하지 않고 총 81개 본문별 부분으로 나눴다. API에서 80개 묶음·81개 부분과 교차 체계 분리를 확인했다. 실제 화면에서는 동일 코퍼스 묶음 한 건의 주장 카드 4건과 교차 코퍼스 묶음에서 분리된 두 항목의 각 카드 1건을 확인했다. 이는 80개 묶음을 전수 화면 시험한 결과는 아니다.

D-15/D-16의 모델링된 참조는 주장 검토 47/47, D-12 필드 감사 44/44, 중복 검토 3/3, 관계 근거 1/1, 관계 1/1, 권리 근거 24/24로 확인됐다. D-12 필드 감사 7건의 선택적 출처가 없으며 미해결 필수 참조 및 모델링한 사슬 충돌은 0건이다. 참조가 존재한다는 사실은 직접 반박·공식 교리·학술 심사 또는 권리 허가를 확정하지 않는다. [비식별 참조 집계](../reports/k37-private/review-reference-aggregate.log)

신규 주장 145건의 `statement_ko`와 `reasoning_ko`는 각각 표시 가능 0건이다. 개별 자체 서술·비인용 확인 근거가 없어 두 필드 모두 보류하며 원문 또는 법적 금지라고 단정하지 않는다. 원본 발화자 표기 145건과 전통 라벨 35건은 귀속이 확인되지 않은 원본 기록으로만 취급하고 확인된 발화 주체로 승격한 건수는 0이다. 기존 D-12 표시 요지 9건과 보류 35건은 그대로 보존한다. [비식별 표시 집계](../reports/k37-private/content-actual.log)

## 보호 원칙

서지, 주장, 논거와 관계의 수신·표시 판정은 출처 확인, 공식 채택 및 독립 학술 심사와 별개다. 문헌 작성자와 주장 발화자를 자동으로 동일시하지 않고 외부 비평을 공동체 자신의 진술로 전환하지 않는다. 근거가 부족한 직접 반박·귀속은 보류한다. 자체 서술과 보호받는 원문·장문 인용을 구별하며 미확정 권리를 자동 공개 승인하지 않는다.

실제 연구값, 원시 식별자, 주소, 개인정보, 원문 및 자료 파일은 공개 저장소·CI·진단 로그·모델 출력에 넣지 않는다. 공개 테스트는 합성 자료로만 실행하고, 실자료 검증 결과는 고정 수치와 불리언만 기록한다. 예전 J-3 연구자료 도구 출력 사고는 후속 시험 통과로 소급 복구되지 않는다.
