# SCRIPTURA C-03 — 실제 W10R 로컬 정본·AI 연구 화면

**신규 기능은 기존 SCRIPTURA 비공개 웹 서버와 같은 인증·루프백 경계를 사용합니다.**
구버전 D13/D14 탐색기 실행과 연구 원본은 바꾸지 않았습니다.

## 시작 (Windows)

1. 코드 브랜치 codex/scriptura-c03-canonical-local-ai 를 내려받습니다.
2. Library에서 다운로드한 /Works/SCRIPTURA/canonical/SCRIPTURA_RESEARCH_CANONICAL.zip 원본을
   Git 저장소 바깥의 개인 폴더에 보관합니다 (압축 해제하지 않음).
3. START_SCRIPTURA_CANONICAL.cmd 를 실행하여 정본 ZIP을 고릅니다.
4. Ollama 로컬 모델이 이 PC에 **이미 설치·실행**돼 있다면 y를 선택하고
   실제 ollama list 결과에 있는 모델명을 입력합니다. 없다면 N을 선택합니다.
   모델은 설치·기동되지 않으며, 없는 모델일 때 실제 추론은 성공하지 않습니다.
5. 터미널에서 20자 이상 세션 비밀을 정해 브라우저에서 입력합니다.
6. 통합 정본 · AI 연구 탭에서 본문 표기 검색 → 실제 해석 요지/논거 조회
   → 질문을 입력하여 로컬 AI 분석을 요청합니다.

## 보안·해석 한계

- W10R SHA-256 고정: d866d395942a3717d58b06e1cfab5e28155f68ace2788e0f4118dfb5336e5f81.
  정본이 갱신되면 코드에 등록된 신뢰 앵커도 안전하게 갱신해야 합니다.
- 오직 127.0.0.1:11434 에 설치된 Ollama 모델만 호출하며, 프록시는 사용하지 않습니다.
  API 사용을 사용자가 명시적으로 켰을 때만 비공개 연구 입력 후보를 전송합니다.
  다만 사용자 PC에 설치된 프로그램 자체의 동작은 별도 검증 대상입니다.
- AI에게 원문 전문·장문 원전·URL을 보내지 않습니다.
  단문 연구 요지·논거도 원전 정확성·인용 여부·재사용 권리 미확정입니다.
- 정경·판본 동등성 미확정 본문은 원본 본문 ID로만 찾습니다.
  검색 문자열이 비슷해도 직접 같은 본문으로 자동 병합하지 않습니다.
- AI 출력의 citation은 실제 전달된 후보 ID 중 존재 여부만 검사합니다.
  그 주장이 인용한 근거에 의해 *의미적으로 입증되는지*를 확인한 것은 아닙니다.
  확인되지 않은 교단 공식성과 신학 결론을 승격하지 않습니다.
- 본 시스템은 비공개 로컬 시범 기능입니다. 정본 자동 업로드, 공개 배포,
  외부 모델 호출, 인간 학술심사 또는 법적 이용권 판정은 수행하지 않습니다.

## 수용 검사

- 두 입력 유형(D13+D14 기존 모드, 신규 W10R 통합 모드)을 각각 실행한다.
- W10R: 856 출처 / 965 주장 / 812 본문 / 750 논거 기록을 직접 읽는다.
- 서로 다른 주소가 인용·정경 관계의 자동 동등성을 만들지 않는지 확인한다.
- 미로그인 요청 401, 외부 출처 공격 403, 명시적으로 모델 연결하지 않은 상태 model_unavailable.
- 실제 로컬 모델의 성공 여부는 모델이 설치된 사용자 Windows에서만 판정한다.
- W-11 기존 50문항 벤치마크는 별도, 실제 모델 실행 전에는 NOT_RUN으로 유지한다.
