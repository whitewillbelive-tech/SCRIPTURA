# 의사 결정 기록

## 채택 — 2026-11-05 / S-0

- 신규 프로젝트를 SCRIPTURA(가칭)로 분리한다.
- 저장·검증·그래프·AI 평가를 서로 분리한다.
- 전체 데이터 수집보다 '본문/해석 주장/출처/검증' 표준을 먼저 구현한다.
- 정경·장절 체계는 다중으로 지원한다.
- 공식 교리와 개인 견해를 분리한다.
- 저작권 미확인 자료는 `metadata_only`를 기본으로 한다.
- DB 초안은 PostgreSQL, 웹은 Next.js + TypeScript를 제안한다.
- 첫 실증은 합성 테스트 및 실출처를 검증한 2개 본문으로 나눈다.
- Codex와 Work는 별도 트랙, 사용자 승인을 받아 Gate 통합한다.

## 미결 — 승인 필요한 사항

- 공식 프로젝트명, 공개/비공개 운영 모델
- 배포 호스팅 및 도메인
- 연구 데이터 접근 제어·사용자 계정
- 신학적 평가의 기본 모드와 어떤 해석 원칙을 기본으로 삼을지
- 유료 출판물 권리 취득 여부, 외부 파트너 협업
- 실제 본문 매핑 기준판 및 번역본 선택

## 보류된 제안

- Neo4j 도입: 실제 PostgreSQL 관계 탐색 성능이 부족할 때 재평가
- 자체 파인튜닝: 수집·검증 데이터가 충분히 확보된 이후 검토
- 그래프 전체 자동 생성: 오류 확산 방지를 위해 사람의 승인 단계 필수
