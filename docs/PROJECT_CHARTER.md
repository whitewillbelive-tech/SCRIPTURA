# SCRIPTURA 프로젝트 헌장 — S-0 / 2026-11-05

## 사명

세계적으로 접근할 수 있는 성경 해석 관련 지식(유대교, 기독교 제전통, 이슬람의 성경 인물·서사 관련 해석, 신흥 종교, 학계, 개인 강연)을 **검증 가능한 출처와 함께** 연결·보존하고, 본문 및 논증 단위로 비교 가능한 연구 플랫폼을 만든다.

## 핵심 사용자 시나리오

- 본문 중심: 특정 구절을 열어 정경·원문·역본·주석·관련 경전·학술 논문을 비교한다.
- 견해 중심: 집단·개인·학파별 주장을 검색하되 공식 교리인지 개인 의견인지 명시한다.
- 논증 중심: 특정 주장의 전제, 원어·문맥 근거, 다른 본문 인용, 반론을 추적한다.
- 질문 중심: AI가 증거를 제시하고 방법론(역사언어/정경/교리/논리)을 분리해 평가한다.

## 고정된 원칙

- 모든 전통을 연구 자료로 다루되 모든 주장을 동일한 권위로 취급하지 않는다.
- 아카이브는 정통/이단/사이비를 무조건적인 단일 '사실 라벨'로 등록하지 않는다. 특정 평가의 **주체·기준·자료·시점**을 별도 주장으로 기록한다.
- 소속 종교와 개인의 주장, 명목상 소속과 공식 채택을 혼동하지 않는다.
- 이슬람의 꾸란·타프시르 등은 독립 코퍼스에 저장하고 본문·주제와 연결한다.
- 본문·장절 표기는 하나의 정경 체계에 고정하지 않으며 이견과 불확실성을 표현한다.
- 탐색 그래프의 모든 실질 연결선은 출처와 관계 유형을 가진다.
- 자료의 미확인 상태, 부족한 관점과 최신 수집 시점을 사용자에게 표시한다.
- AI 판단 결과는 비교·추론 산출물이며 검증된 원사료와 구분한다.

## 비범위 (첫 번째 개발 반복)

- 시중 번역본·상업 주석의 무허가 복제, 전체 학술 논문 크롤링
- 실제 외부 사이트 자동 대량 수집 또는 사용자 무동의 재배포
- 전 종교·전 교파의 누락 없는 최종 분류 체계 확정
- 성경의 모든 구절에 대해 즉시 단일 '참/거짓 교리 판결' 제공
- 기존 성경 시공간 아틀라스, UTT 데이터 원천의 수정·이전
- 운영 환경이나 사이트의 자동 게시

## 거버넌스

- 사용자가 자료·기능 범위·신학적 판정 기준의 최종 제품 결정을 내린다.
- 학술 분류 및 해석 검증은 원문·학계와 공식 교리 문헌에 비추어 재현 가능한 검수 규칙을 따른다.
- '자료 저장 승인'과 'AI 판정 신뢰성 승인'을 별개 단계로 취급한다.
- 모든 변경 사항을 작업 이력·버전·출처 해시로 역추적할 수 있도록 한다.

## 시범 검증 구절 후보

이사야 7:14, 요한복음 1:1, 마태복음 16:18, 로마서 3:28, 야고보서 2:24, 창세기 1:1. 이들은 '논쟁 가능성을 검증하기 위한 후보'이며, 실제 인용·해석 등록은 원문 확인 후 실시한다. 첫 반복에는 2개 본문을 실증하고 20~30개로 확장 여부를 판단한다.

## 독립성

새 프로젝트 및 저장소를 기본으로 한다. 추후 UTT·성경 시공간 아틀라스와 연계하더라도 API 기반의 선택적 참조만 허용하고, 기존 앱의 데이터 원천이나 배포 흐름을 변경하지 않는다.
