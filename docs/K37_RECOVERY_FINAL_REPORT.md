# K-3~K-7 실자료 복구 추가 검증

이 작업은 `ae08ca2bc01479f01911fe47c5c6e4391d739be9`의 후손인 기존 비공개 통합 결과를 보존해 수행했다. 제공된 두 연구 ZIP은 직전 통합 입력과 일치했으며 제공된 사전 검사는 `READY_FOR_PRIVATE_INTEGRATION`이었다. 실자료의 원문·식별자·URL과 파일은 저장소와 공개 CI에 포함하지 않는다.

실제 D-13의 출처 47건·주장 47건, D-14의 출처 96건·주장 98건·신규 본문 45건, 기존 후보 621건이 수신되어 후보가 909건이다. D-13과 D-14는 각각 앞선 유효 계보를 기준으로 참조와 사슬을 검사하며, 이번 실자료의 격리는 각각 0건이다. 입력 건수와 실제 수용 건수는 따로 집계한다.

D-16 비교 묶음 80건에는 주장 참조 177건과 본문 참조 81건이 있다. 각 주소에 실제로 연결된 구성원이 있어야 검증 완료로 취급하며, 코퍼스나 주소 체계가 다른 항목은 병합하지 않는다. 80개 묶음은 81개 주소별 비교 화면으로 연결된다.

실제 자료를 사용하는 Linux Chromium에서 81개 분할의 API 구성원과 화면 카드 및 이전 결과 제거를 각각 81/81 확인했다. 1366×768의 검색·전통 필터·상세·키보드·비교 선택도 통과했다. 1280×720의 상세 버튼 접근은 수정 후 통과했으며 해당 해상도의 K-6 전체 회귀는 추가 확인 중이다. [비식별 브라우저 로그](../reports/k37-private/actual-browser-full.log)

신규 주장 145건에는 요지와 논거가 각각 기록되어 있으나 필드별 자체 요약·비인용 및 원문 미저장 근거를 모두 충족하는 것은 각각 0건이다. 표시 보류는 그 근거가 확인되지 않았다는 뜻이며, 원문이거나 법적으로 금지됐다는 판정이 아니다. D-12 보류 35건도 새 감사 기록으로 정당하게 해제할 수 있는 근거가 0건이었다. 기존 D-12 표시 가능 요지는 유지한다. 확인된 해석 발화자와 문헌 작성자는 동일시하지 않고, 원본 발화자 표기는 독립 확인 전 상태로 검색한다.

D-16 권리 근거 24건의 관련 출처·판본 참조는 확인됐다. 세 건에는 원문·인용 관련 제한 표현이 있지만 서지 필드의 명시적 제한을 확인하지 못했다. 자유 서술에서 허용 또는 금지를 추측하지 않는다. 향후 기계적으로 해석 가능한 명시적 제한은 검증된 출처·판본과 해당 필드에 연결하며, 미적용 제한은 별도로 보류한다. 제한 적용은 허용이나 학술 검증을 의미하지 않는다.

기존 사용자가 확인한 K-2 Windows 7/7과 이번 Linux 자동시험은 별개다. 이번 통합 버전의 사용자 Windows 실기기 시험은 수행하지 않았다. [Windows 실행 및 수용 절차](../K37_PRIVATE_WINDOWS_KO.md)를 참고한다.

최종 코드의 합성 Python 전체 시험은 579 PASS / 0 FAIL / 0 SKIP이다. [실행 로그](../reports/k37-private/python-recovery-final.log). 합성 API 시험은 6 PASS / 0 FAIL / 0 SKIP이다. [실행 로그](../reports/k37-private/npm-api-recovery-final.log). 두 시험은 처음에 샌드박스의 루프백 소켓 제한으로 실패하여, 로컬 네트워크 권한으로 재실행했다. 실제 자료와 합성 시험은 분리했다.

합성 Chromium 통합 UI 시험은 시스템 Chromium을 지정해 5 PASS / 0 FAIL / 0 SKIP으로 통과했다. [실행 로그](../reports/k37-private/ui-synthetic-recovery-final.log). 1280×720에서 비교 결과 영역이 0픽셀로 줄어 상세 버튼에 마우스로 접근하지 못하던 문제를 수정하고 회귀시험을 추가했다. 최초 실행은 Playwright가 다운로드한 브라우저가 없어 실패했다.

공개 커밋 전 실제 ZIP의 값과 변경 사항을 메모리에서 대조해 원시 식별자·URL·제목·장문·해시의 정확 일치를 검사했다. 변형된 내용까지 완전히 탐지하는 검사는 아니며 연구값을 로그에 기록하지 않는다.

실자료 기반 완전한 K-3~K-7 완료는 **PENDING**이다. 신규 주장과 논거가 표시 가능 0건이고, 검증된 발화자 귀속과 표현별 권리 근거가 부족하다. 운영 DB 쓰기, main 병합, 운영 배포 및 정본 자동 승격은 수행하지 않는다.
