# 제안된 범용 수신 계약의 로컬 시험

이 도구는 `scriptura.research-archive.v1` 매니페스트를 가진 **별도 신규 형식**을 읽는다. 기존 D-8~D-13 Work ZIP이 이 형식과 호환된다는 뜻이 아니다. D-13 원본을 확보하지 못한 현재 실제 스키마 대응과 기존 탐색기 연결은 검증하지 않았다. 이 도구는 연구 원본을 변경하거나 데이터베이스에 쓰지 않는다.

매니페스트는 `schema`, `version`, `baseline_sha256`, `files`를 포함한다. `version`은 `D`와 양의 정수로 나타내며 후속 증분은 이전 버전보다 커야 한다. `files`의 각 항목은 `path`, `table`, `sha256`, `count`를 갖고, 지정된 `records/<table>.jsonl`과 정확히 대응한다. 아카이브의 해시만 자체적으로 읽어 신뢰하지 않는다. 독립적으로 인증된 기준 ZIP·매니페스트 및 증분 ZIP·매니페스트 신뢰 앵커가 별도로 필요하다.

로컬 사용자만 읽을 수 있는 별도의 신뢰 정책 파일은 다음 키를 포함한다. 값은 외부 경로로 각각 검증한 SHA-256 소문자 64자여야 한다. 예시의 꺾쇠 값은 실제 값이 아니다.

```json
{
  "schema": "scriptura.local-trust-policy.v1",
  "baseline_archive_sha256": "<인증한 기준 ZIP 해시>",
  "baseline_manifest_sha256": "<인증한 기준 매니페스트 해시>",
  "baseline_root_sha256": "<인증한 기준 매니페스트의 이전 기준 해시>",
  "increment_archive_sha256": "<인증한 증분 ZIP 해시>",
  "increment_manifest_sha256": "<인증한 증분 매니페스트 해시>"
}
```

기준 ZIP은 이전 레코드를 참조하지 않는 자체 완결된 v1 자료여야 하며, 잘못된 기준 행이 있으면 전체 기준을 거부한다. 증분의 잘못된 행과 그 의존 행은 격리하고 기존 기준은 메모리에서 그대로 유지한다. 별도의 문헌 중복 후보 집계는 자동 병합이 아니다. 자료에 정의되지 않은 정경·주소 대응을 만들지 않는다.

```powershell
py -3 scripts\validate_research_increment.py --baseline '<기준 ZIP>' --increment '<증분 ZIP>' --trust-policy '<신뢰 정책 JSON>'
```

이 명령은 외부 네트워크와 DB를 사용하지 않고 고정 키의 숫자·불리언 집계만 출력한다. 원본 파일·정책을 전후 재읽어 변경 여부를 확인한다. 터미널 명령 인자는 운영체제 프로세스 목록이나 셸 이력에 남을 수 있으므로 개인 로컬 계정을 사용하고 실제 경로나 해시를 공유하지 않는다. 연구 원문·개인정보·원시 자료 ID는 출력하지 않는다. 사용자 제공 trust 파일이 올바르다는 자체 보장은 없으며, 승인되지 않은 ZIP과 함께 동봉된 정책을 신뢰 근거로 사용해서는 안 된다.
