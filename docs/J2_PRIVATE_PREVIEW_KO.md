# J-2 비공개 연구 후보 탐색기

이 화면은 로컬에서 동결 D-8 연구 자료를 확인하는 읽기 전용 후보 탐색기다. 원본을 수정하거나 운영 DB에 기록하지 않으며, 출처 확인을 학술 검수·공식 교리 채택·자료 이용 허가로 승격하지 않는다. 화면에 나타난 항목은 실자료를 이용한 연구 후보이며 실제 독립 인간 학술 심사가 끝난 자료라는 뜻이 아니다.

계약상 각 실제 필드의 표시 자격 확인은 **PENDING**이며 어떤 필드도 `candidate_visible_local`로 승격하지 않는다. 실제 D-8 자료의 문헌명·저자·발화자·연구자와 공동체 이름은 가리므로 해당 이름이나 문헌명으로 검색할 수 없다. 숨긴 값을 이용한 검색이나 추론 검색도 제공하지 않는다. 이름을 사용하는 예시는 합성 시험에서만 사용한다. 현 단계의 탐색은 정형 DOI·연도·상태·코퍼스와 장절 주소 및 안전 식별자를 중심으로 한다. 출처 원문, 직접 인용, 자유 서술 요약과 URL도 가리고, `unknown`·`conditional` 권리를 이용 허가로 바꾸지 않는다. 판본·인용과 논증·공식 채택·인간 검수·권리는 독립 상태다. 로컬에서 화면을 보는 것은 링크의 공개 또는 자료 재배포 권한이 아니다.

## Windows 사전 준비

- Windows PC에 Python 3.10 이상과 기본 웹 브라우저를 준비한다. PowerShell에서 `py -3 --version`으로 확인한다. 탐색기는 Python 표준 라이브러리만 사용하며 Node.js는 필요하지 않다. Git은 코드를 내려받을 때만 필요하다.
- Git이 설치되어 있다면 PowerShell에서 개인 사용자 폴더로 이동한 뒤 아래 명령으로 이 개발 브랜치를 준비한다. 이미 해당 브랜치가 있다면 기존 프로젝트를 사용할 수 있다. 원본 ZIP은 프로젝트 또는 공개 동기화 폴더가 아닌 개인이 접근을 제어하는 위치에 둔다.
- 제공받은 인계 ZIP의 `baseline/SCRIPTURA_D8_RESEARCH.zip`을 PC의 개인 오프라인 로컬 드라이브 폴더에 추출한다. UNC 경로와 URL은 거부되지만 매핑된 네트워크 드라이브나 네트워크 마운트는 코드가 완전히 탐지할 수 없으므로 사용자가 직접 로컬 드라이브인지 확인해야 한다. Windows 파일 탐색기에서 인계 ZIP을 열어 해당 파일만 복사해도 된다. 다른 이름의 임의 ZIP을 같은 자료로 추정하지 않는다. 탐색기는 고정 해시와 중첩 무결성을 검사한다.
- 이 문서는 실행 방법이며 **Windows에서는 아직 실행·검증하지 않았다(NOT_RUN)**. 클라우드의 `localhost`는 Windows PC의 주소가 아니다.

```powershell
git clone --branch codex/scriptura-j2-private-candidate-preview https://github.com/whitewillbelive-tech/SCRIPTURA.git
Set-Location SCRIPTURA
```

## 실행 및 종료

PowerShell을 열어 프로젝트 폴더로 이동한 뒤, 아래 예시의 ZIP 경로만 본인이 준비한 D-8 파일 경로로 바꿔 실행한다.

```powershell
py -3 scripts\j2_private_preview.py --archive 'C:\Users\사용자\Documents\SCRIPTURA-private\SCRIPTURA_D8_RESEARCH.zip'
```

서버 시작 시 터미널에서 추측하기 어려운 20자 이상의 ASCII 비밀 문구를 입력한다. 입력 가능한 문자는 영문·숫자·기호와 공백이며 제어 문자와 한글은 사용할 수 없다. 다른 서비스에서 사용하지 않는 길고 무작위성이 높은 문구를 직접 선택한다. 입력 문자는 화면에 나타나지 않는다. 서버가 루프백 주소와 운영체제가 선택한 포트를 사용하고 브라우저를 열면, 화면의 비밀번호 입력란에 같은 비밀 문구를 다시 입력한다. 브라우저가 자동으로 열리지 않으면 터미널에 표시되는 `127.0.0.1` 주소를 같은 PC의 브라우저에서 직접 연다. 이 주소에는 비밀 문구나 자료 경로가 없다. 서버는 선택한 원본을 읽기 전용으로 사용한다. 탐색이 끝나면 명령을 실행한 PowerShell에서 `Ctrl+C`를 눌러 서버를 종료하고 브라우저 탭을 닫는다. 원본 파일이 없거나 해시·구조가 다르면 터미널에 오류를 표시하고 서버를 시작하지 않는다. 합성 예시로 자동 대체하지 않는다.

## 로컬 보안 및 운영 범위

서버는 루프백으로 제한하고 세션의 비밀 문구를 확인한다. 인증이 5회 연속 실패하면 서버 전체에서 10초 동안 올바른 문구도 거부하므로, 잠시 기다린 뒤 다시 입력한다. 프로세스를 다시 시작하면 이 카운터는 초기화된다. 비밀 문구를 명령행 인자·환경 변수·URL·로그에 넣거나 다른 사람과 공유하지 않는다. 같은 PC의 사용자 프로필에 접근할 수 있는 다른 계정이나 악성 코드가 있으면 토큰·브라우저 세션·화면을 보호한다고 보장할 수 없다. 공용 PC나 공유 계정에서는 실행하지 말고, 사용자 폴더 및 ZIP의 접근 권한을 운영체제에서 제한한다. 앱은 입력 경로·비밀 문구·자료를 요청 로그에 기록하지 않는다. 다만 `--archive` 경로는 실행 명령의 일부이므로 운영체제 프로세스 목록이나 PowerShell 기록에 남을 수 있다. 해당 PC의 접근 권한과 기록 정책을 사용자가 관리해야 한다. 파일 경로와 비밀 문구, 자료 원문·개별 결과 카드를 스크린샷·원격 분석 또는 GitHub에 보내지 않는다.

자료의 source 확인은 독립 인간 학술 심사, 공동체의 정식 채택, 논증의 성립이나 저작권 허가와 별개다. 권리 필터는 같은 행위의 원래 판단 또는 별도 추가 관찰의 새 판단을 검색하며, 그 어느 결과도 실제 이용 허가가 아니다. 매핑할 수 없는 구조는 stage·table·mapping 상태만 출력한다. 오류나 권리 확인 부족으로 숨긴 필드는 검토가 끝난 것으로 추정하지 않는다. 이 구현은 임시 로컬 연구 검토에만 사용하며 공개 서비스, 운영 배포, 운영 PostgreSQL 쓰기와 정본 승격은 제공하지 않는다.

## 설정과 검증

| 설정 | 용도 |
|---|---|
| `--archive` | 사용자가 선택한 고정 D-8 ZIP의 로컬 경로. 필수이며 시작 명령에만 지정한다. |
| 세션 비밀 | 실행 중 터미널에서 숨김 입력하고 브라우저에서 재입력한다. 환경 변수나 URL에 설정하지 않는다. |
| `DATABASE_URL` | J-2 탐색기는 PostgreSQL에 연결하지 않으므로 필요하지 않다. |

검증용 합성 브라우저 시험은 저장소에서 Python과 별도 Playwright/Chromium 개발 의존성을 준비한 뒤 `node tests/ui-j2-candidate.browser.cjs`로 실행한다. 이 시험의 데이터는 전부 합성이며 실제 연구 ZIP을 읽지 않는다. 실제 D-8을 이용한 검증 기록은 개인별 카드, 경로와 원문 없이 건수·상태만 남겨야 한다.
